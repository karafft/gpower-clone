# Kaynak kayıtları

sude_protocol_vectors.jsonl60 metin protokol kaydını içerir; özgün metin
sude_protocol_text.txt altındadır. sude_contract_compatible_vectors.jsonl
aynı setten sözleşmeyle çelişen iki GUI başarı kaydını ayrı tutar. Bunların
kimlikleri ORC050 ve059; sessizce silinmediler. final60_audit.json her iki
durumu, kaynak eşleşmesini ve sözleşme kontrolünü ayrı raporlar.

reference_manifest.json resmî binary'nin sürüm/hash/kaynağıdır;
binary_evidence.json statik referansları içerir. Özgün binary yoktur.
scale/ bağımsız kütüphane verisidir; oracle diye puanlanmaz.

Henüz yeni saklı VAL seti veya özgün ekran görüntüsü eklenmedi. Kaynak set
geliştirmede kullanıldığı için bağımsız doğrulama diye yeniden etiketlenmez.
