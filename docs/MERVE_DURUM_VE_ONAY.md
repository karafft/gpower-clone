# Merve durum ve ekip onayı

**Sonraki kapsam güncellemesi:** Kullanıcının isteğiyle MCP sunucusu,
API destekli ajan kodu, karşılaştırma aracı ve 540 ölçek çalışması da
hazırlandı. Aşağıdaki metin ilk motor paketinin onay notudur; güncel
durum README ve EKIP_TAMAMLANANLAR.md içindedir. Canlı LLM ve gerçek
G*Power/REA doğrulaması tamamlanmış sayılmaz.

Yerel inceleme paketi hazırlanmıştır; yayımlanmamıştır.

Tamamlananlar: beş t2-indep modu, ortak motor API'si, ince CLI adaptörü,
girdi doğrulaması, src paket düzeni, pyproject konsol tanımı, motor ve CLI
testlerinin ayrılması, Türkçe kullanım/rapor/devir/köken belgeleri.
Çalıştırılan test ve kurulum sonuçlarının güncel kaydı REPORT.md içindedir.

Ekipten bu somut paketin incelemesi ve onayı istenir. Sude'nin REA destekli
davranış doğrulaması ve saklı oracle karşılaştırması **bekliyor**. Zeliha'nın
MCP entegrasyonu **bekliyor**; bu pakette MCP uygulaması yoktur.

Onay verilmiş kabul edilmez. G*Power eşdeğerliği veya yüzde doğruluk iddiası
yoktur. Açık kararlar MERVE_ACIK_KONULAR.md dosyasındadır.
