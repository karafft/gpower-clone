#60 saniyelik CLI anlatımı

CLI_Demo_60s.mp4 gerçekten çalıştırılan beş komutun stdout kayıtlarından
oluşturulmuş açıklayıcı videodur. Kaynak cli_transcript.json. Altıncı bölüm
gerçek raporların kapsamını açıklar. Video terminal veya G*Power ekran kaydı
değildir; kaynak görüntüsü veya canlı LLM çıktısı uydurulmadı.

Yeniden üretim: Pillow ve imageio-ffmpeg kurulu bir ortamda
python tools/build_demo.py --frames work/demo_frames --output demo/CLI_Demo_60s.mp4
Komut kayıtları güncellenirse önce gerçek CLI koşumlarıyla yenilenmelidir.
